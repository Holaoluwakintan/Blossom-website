# Display covers

Front-panel crops of uploaded book artwork, served in place of the Supabase upload
(mapped by slug in `src/lib/book-downloads.ts`). Replace a file here, or delete its
entry from `displayCoverOverrides`, once a clean front-cover file is uploaded.

- crack-the-algorithm.webp: front panel of the full wraparound (back + spine + front).
- the-power-of-choices.webp: front face cut from a 3D mockup render on black.
- hungry-generation.webp: front cover cut from a photographed back+front mockup (only 408 px wide; needs the original file).
- similoluwa.webp: cover cut from a mockup on a red mat.
